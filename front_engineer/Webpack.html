    # 函数式配置

    # 核心参数

    1. env (环境变量参数) 通过Webpack 命令行的 --env 选项传入

      • 传入单个环境标识: webpack --env prod (此时 env = prod)
      • 传入多个环境标识: webpack --env mode=prod --env url=xxx (此时 env = {mode: 'prod', url: 'xxx'})

    2. argv (命令行参数对象) 接收Webpack 命令行的所有参数解析结果 (env 是argv 的子集，仅对应 --env 相关参数)

      • webpack --mode prod --watch --custom-flag

        (此时 argv = {mode: 'prod', watch: true, custom-flag: true})

    3. options (Webpack内置选项对象) 提供 Webpack 内部的配置上下文信息

      • 核心属性：

        属性名 含义说明 示例值
        context Webpack 配置的根目录（默认是配置文件所在目录） '/Users/xxx/project'
        config 原始配置对象（未解析前的配置） { entry: './src/index.js' }
        configPath 配置文件的绝对路径 '/Users/xxx/project/webpack.config.js'
        env 与第一个参数 env 一致（冗余但便于插件统一获取） { mode: 'production' }

    # 工具

    1. cross-env 统一跨平台的环境变量设置语法, 定义的变量会被注入到 process.env 对象中，直接通过 process.env.变量名 读取即可

    2. dotenv 将环境变量从 .env 文件中读取解析到对象中

      (e.g. const envConfig = dotenv.config({ path: envFile }).parsed || {})

    3. webpack-merge 将多个 Webpack 配置对象合并成一个

      (e.g. const { merge } = require('webpack-merge'); module.exports = merge(baseConfig,{}))

    4. webpack-dev-server 开发环境服务器工具

      配置项 作用 示例
      static 指定静态文件目录（如 HTML、图片等） static: './public'
      port 服务器端口，默认 8080 port: 8000
      open 启动后是否自动打开浏览器 open: true（自动打开）
      hot 启用热模块替换（HMR） hot: true（需配合 HotModuleReplacementPlugin, 特殊情况：Webpack 5+ 的自动处理）
      compress 对所有请求启用 gzip 压缩 compress: true
      proxy 配置 API 代理（解决跨域） {
      context: ['/api', '/auth'], // 需要被代理的请求路径（数组形式，可配置多个）
      target: 'http://localhost:5000', // 后端服务器的基础地址（代理目标）
      pathRewrite: { '^/api': '' }, // 可选：重写请求路径（移除/api前缀）
      changeOrigin: true, // 可选：支持跨域（修改请求头中的Host）
      secure: false // 可选：若目标是https，设为false可忽略证书验证
      }
      historyApiFallback 支持 SPA 路由（如 React Router、Vue Router 的 history 模式） historyApiFallback: true
      client 配置客户端日志和提示 client: { overlay: true }（编译错误时在浏览器显示浮层）

    # 配置项

    # devtool

    关键字 含义
    eval 用 eval() 执行模块代码，Source Map 以 //# sourceURL 形式嵌入代码中（不生成独立 .map 文件），构建速度极快。
    source-map 生成独立的 .map 文件（如 main.js.map），包含完整映射信息，调试体验最佳，但构建最慢。
    cheap 只映射行号，忽略列号（调试时误差在一行内），构建速度更快。
    module 映射到「原始源代码」（如 TypeScript、Vue 单文件），而非「转译后的代码」（如 Babel 处理后的 JS）。
    inline Source Map 嵌入到输出文件中（而非独立 .map 文件），会增加输出文件体积。
    hidden 生成独立 .map 文件，但输出文件中不添加 //# sourceMappingURL 注释（浏览器不会自动加载，需手动添加）。
    nosources 生成的 Source Map 只包含映射关系（行号 / 列号），但不包含原始代码内容（保护源码，仅用于定位错误位置）。

    # splitChunks

    对比项 默认行为（不设置 enforce: true） 强制分包（设置 enforce: true）
    触发条件 需同时满足多项限制（体积、引用次数、请求数量等） 忽略所有限制，只要模块匹配 test 规则就会拆分
    minSize 限制 模块体积 ≥ 20KB（默认值） 无视体积大小，即使模块只有几 KB 也会拆分
    minChunks 限制 同步模块需被 ≥ 3 个 chunk 引用，异步模块需被 ≥ 1 个 chunk 引用（默认值） 无视引用次数，即使只被引用 1 次也会拆分
    maxRequests 限制 受限于 maxAsyncRequests（30）和 maxInitialRequests（30），避免请求过多 无视请求数量限制，可能导致 chunk 数量激增
    适用场景 大型模块（如第三方库）、被频繁复用的公共代码（引用次数多） 小型但需独立缓存的模块（如工具类）、按需加载的组件、必须单独拆分的业务模块
    优势 避免过度拆分，减少 HTTP 请求，平衡性能和代码冗余 灵活控制拆分逻辑，满足特殊业务需求（如独立缓存、按需加载）
    劣势 无法拆分小体积或低引用次数的模块，可能导致代码重复 可能生成大量小额 chunk，增加请求开销，降低加载性能

    # 通过环境变量参数修改配置对象 (函数式)

    webpack需要利用dotenv工具来注入.env文件中设置的环境变量

    const path = require('path')
const dotenv = require('dotenv')
const HTMLWebpackPlugin = require('html-webpack-plugin')
const { VueLoaderPlugin } = require('vue-loader')
const webpack = require('webpack')
const BundleAnalyzerPlugin = require('webpack-bundle-analyzer').BundleAnalyzerPlugin
const CompressionPlugin = require('compression-webpack-plugin')
const MiniCssExtractPlugin = require('mini-css-extract-plugin')

module.exports = (env, argv, options) => {
    const mode = env.mode || 'dev'
    const envFile = `.env.${mode}`
    const config = dotenv.config({path: envFile}).parsed || {}
    
    const defineEnv = {}
    for(const key in config){
        defineEnv[`process.env.${key}`] = JSON.stringify(config[key])
    }
    
    const isProd = mode === 'prod'
    
    const plugins = [
        new HTMLWebpackPlugin({
            template: './src/index.html',
            templateParameters: {
                title: config.SYSTEM_TITLE || '默认标题'
            }
        }),
        new VueLoaderPlugin(),
        new webpack.DefinePlugin(defineEnv)
    ]
    let cssRule = 'style-loader'
    
    if(isProd){
        plugins.push(
            new BundleAnalyzerPlugin({
                /**
                * 'server': 启动本地服务器，通过'localhost'访问
                * 'static': 生成静态HTML文件，默认输出到'dist/report.html'
                * 'disabled': 禁用，可通过'BundleAnalyzerPlugin.getBundleReport()'手动获取报告数据
                */
                analyzerMode: 'server',
                analyzerPort: 8080,
                openAnalyzer: false,
                /**
                * 'silent': 不输出日志
                * 'warn': 仅输出警告信息
                * 'info'(默认): 输出基本启动信息(如服务器地址)
                * 'debug': 输出调试信息(适合排查插件问题)
                */
                logLevel: 'info'
            }),
            new CompressionPlugin({
                /**
                * [path]: 保留原文件目录结构(js/index.js -> js/)
                * [base]: 保留原文件名称及后缀(index.js -> index.js.gz)
                */
                filename: '[path][base].gz',
                algorithm: 'gzip',
                test: /\.(js|css|html|svg|json|png)$/,
                threshold: 10240,
                minRatio: 0.8
            }),
            new MiniCssExtractPlugin({
                // 入口chunk对应的css输出文件名(如通过entry配置的主文件)
                filename: '[name][contenthash].css',
                // 非入口chunk对应的css输出文件名(如通过import()动态导入生成的chunk)
                // [id]: chunk的数字id(webpack自动分配)
                chunkFilename: '[id].css',
                // 控制是否忽略因css导入顺序不同导致的警告
                ignoreOrder: true
            })
        )
        cssRule = MiniCssExtractPlugin.loader
    }
    
    const devServer = !isProd ? {
        host: 'localhost',
        port: 3000,
        proxy: [
            {
                context: ['/api'],
                target: config.PROXY_URL,
                changeOrigin: true,
            }
        ],
        hot: true,
        open: true
    } : undefined
    
    return {
        mode: isProd ? 'production' : 'development',
        entry: {
            main: './src/main',
            index: './src/index'
        },
        output: {
            path: path.resolve(__dirname, 'dist'),
            filename: isProd ? '[name].[contenthash].bundle.js' : '[name].bundle.js',
            clean: true
        },
		module: {
            rules: [
                {
                    test: /\.js$/,
                    use: ['babel-loader'],
                    exclude: /node_modules/
                },
                {
                    test: /\.ts$/,
                    use: [
                        'babel-loader',
                        {
                            loader: 'ts-loader',
                            options: {
                                appendTsSuffixTo: [/\.vue$/]
                            }
                        }
                    ],
                    exclude: /node_modules/
                },
                {
                    test: /\.css$/,
                    use: [cssRule, 'css-loader'],
                    exclude: /node_modules/
                },
                {
                    test: /\.less$/i,
                    use: [cssRule, 'css-loader', 'less-loader'],
                    exclude: /node_modules/
                },
                {
                    test: /\.(s[ac]ss)$/i,
                    use: [cssRule, 'css-loader', 'sass-loader'],
                    exclude: /node_modules/
                },
                {
                    test: /\.vue$/,
                    use: ['vue-loader'],
                    exclude: /node_modules/
                },
                {
                    test: /\.(mp3|mp4)(\?.*)?$/,
                    type: 'asset/resource'
                },
                {
                    test: /\.(png|jpe?g|gif|svg)(\?.*)?/,
                    type: 'asset/resource'
                }
            ]
        },
        plugins,
        devServer,
        resolve: {
            extensions: ['.js', '.ts', '.vue', '.css', '.less', '.sass', '.scss'],
            alias: {
                '@': path.resolve(__dirname, 'src')
            }
        },
        devtool: isProd ? false : 'eval-cheap-module-source-map',
        optimization: {
            splitChunks: {
                chunks: 'all',
                cacheGroups: {
                    vendor: {
                        test: /[\\/]node_modules[\\/]/,
                        name: 'vendors',
                        priority: 10
                    },
                    common: {
                        minChunks: 2,
                        name: 'common',
                        priority: 5,
                        reuseExistingChunk: true // 默认值
                    },
                	util: {
                        test: /[\\/]src[\\/]utils[\\/]/,
                        name: 'utils',
                        priority: 10,
                        enforce: true
                    }
                }
            },
            runtimeChunk: 'single'
        }
    }
}
